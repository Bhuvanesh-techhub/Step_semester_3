session_11
==========

class problems/
  practise problems/  Java solutions for the 10 coding problems from the Category C practice PDF.
                      Files are named in reverse problem order (10 down to 1).
  doc/                MCQ answer key and written answers to all 5 concept questions.

Assignment problems/
  Five standalone Java solutions, one for each separate assignment PDF:
  1. Height Line-Up (bubble sort)
  2. Prize Table (selection sort, descending)
  3. Library Book Shelf (insertion sort)
  4. Is the Queue in Order? (first inversion)
  5. Dice Throw Tally (counting sort)

All Java files contain a main method with the PDF sample input(s), plus a custom test where useful.
Compile/run from a terminal with: javac FileName.java && java ClassName
No Arrays.sort is used in the assignment solutions.
